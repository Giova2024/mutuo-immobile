# Calcolatore Mutuo Immobile

Applicazione web per calcolare la rata di un mutuo per l'acquisto di un'abitazione: rata mensile, interessi totali, totale rimborsato e piano di ammortamento completo (annuale/mensile).

Costruita con **React**, **TypeScript**, **Vite** e **Tailwind CSS**.

## Funzionalità

- Calcolo della rata mensile con metodo di ammortamento alla francese (rata costante)
- Prezzo immobile, acconto/anticipo, tasso d'interesse annuo e durata configurabili
- Riepilogo di interessi totali e totale rimborsato
- Grafico a ciambella capitale/interessi
- Piano di ammortamento dettagliato, annuale o mensile

## Sviluppo locale

```bash
npm install
npm run dev
```

## Build di produzione

```bash
npm run build
npm run preview
```

## Deploy

Il progetto è pronto per il deploy su [Vercel](https://vercel.com) come sito statico (framework Vite rilevato automaticamente).
